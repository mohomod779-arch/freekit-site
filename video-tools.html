شلون تخلي كلود يمنتج لك فيديو

بدل ما تفتح برنامج مونتاج، تكتب لكلود شنو تريد وهو يبني الفيديو. هذا دليل من الصفر: شنو تجهّز، أي أداة تختار، وشنو تلصق وتكتب بالضبط. ما تحتاج خبرة برمجة، بس تتبع الخطوات بالترتيب.

١ جهّز جهازك٢ اختار أداة٣ الخطواتمصطلحاتملاحظات

١. جهّز جهازك (مرة وحدة)

أربع أشياء، بالترتيب. إذا عندك شي منها جاهز تخطاه. الأوامر تنلصق بالطرفية.

  1. اشتراك Claude

    Claude Code يحتاج حساب Claude: اشتراك (Pro أو Max أو Ultra أو Team أو Enterprise) أو حساب Claude Console. بدون حساب ما يشتغل.

  2. نصّب Claude Code

    هذا البرنامج اللي تكتب له طلبك وهو ينفّذ. تفتح الطرفية (شرحها بالمصطلحات تحت) وتلصق الأمر حسب نظامك:

    macOS / Linux

    Windows (PowerShell)

    Windows (بديل)

    بعدها افتح نافذة طرفية جديدة واكتب الأمر التالي. إذا طلع رقم إصدار، التنصيب نجح:

    أول مرة تشغّل claude يطلب منك تسجيل الدخول بالمتصفح. أول مرة تستعمل الطرفية؟ هذا الدليل الرسمي ↗

  3. نصّب Node.js

    بيئة تشغّل أدوات الفيديو. حمّل نسخة LTS من الموقع الرسمي. HyperFrames تحتاج الإصدار 22 أو أحدث، وOpenMontage تحتاج 18 أو أحدث.

    nodejs.org/en/download ↗

  4. نصّب FFmpeg

    برنامج مجاني يركّب الفيديو ويحوّله لملف MP4. HyperFrames وOpenMontage يحتاجونه.

    macOS

    Linux (Ubuntu / Debian)

    Windows

    حمّل نسخة جاهزة من gyan.dev/ffmpeg/builds ↗ (مدرجة بصفحة FFmpeg الرسمية) وأضفها لمسار النظام PATH.

٢. أي أداة أختار؟

كلها تشتغل مع كلود كود. إذا هذي أول مرة، ابدأ بـHyperFrames.

HyperFrames نبدأ بيها

تكتب الفكرة ويطلع فيديو جاهز: إعلان، شرح، عنوان متحرك. أبسط تنصيب من الثلاثة.

تحتاج: Claude Code + Node.js 22+ + FFmpeg

Remotion

للفيديوهات المبنية على أرقام وجداول ورسوم بيانية (مثلاً فيديو من جدول مبيعاتك). تبنيه بكود React، وكلود يكتب الكود.

تحتاج: Claude Code + Node.js · ترخيص خاص (التفاصيل بالملاحظات)

OpenMontage

استوديو إنتاج كامل بـ12 مسار جاهز. الأقوى والأثقل: تنصيب أطول، وبعض أدواته تحتاج مفاتيح خدمات خارجية.

تحتاج: Claude Code + Python 3.10+ + Node.js 18+ + FFmpeg + Git

٣. الخطوات لكل أداة

اتبع قسم الأداة اللي اخترتها فقط. كل أمر تحته زر COPY. شارة «بالطرفية» يعني تلصقه بالطرفية، و«داخل Claude Code» يعني تكتبه بعد ما تشغّل claude.

HyperFrames

★ 78K · GitHub ↗

  1. افتح الطرفية بأي مجلد

    هذا المجلد اللي راح تنحفظ فيه شغلك. مثلاً مجلد جديد اسمه my-video.

  2. نصّب إضافة HyperFrames

    سطرين، تلصقهم واحد ورا الثاني وتنتظر كل واحد يخلص.

    بالطرفية

  3. شغّل Claude Code

    اكتب claude وانتظر يفتح.

    بالطرفية

  4. اكتب طلبك

    ابدأ الطلب بالأمر /hyperframes:hyperframes ثم اوصف الفيديو بكلامك العادي.

    داخل Claude Code

    النتيجة: كلود يكتب الفيديو بـHTML ويحوّله لملف MP4.

Remotion

★ 71K · GitHub ↗

  1. افتح الطرفية بمجلد المشروع

    أي مجلد تريد تشتغل بيه.

  2. نصّب مهارات Remotion

    هذا الأمر يعلّم كلود أفضل طريقة للعمل بـRemotion.

    بالطرفية

  3. شغّل Claude Code

    اكتب claude.

    بالطرفية

  4. اكتب طلبك

    بعد التنصيب تظهر أوامر مثل /remotion-create. اكتب طلبك بعدها.

    داخل Claude Code

    النتيجة: مشروع Remotion يبني الفيديو من بياناتك.

OpenMontage

★ 76K · GitHub ↗

  1. نزّل المشروع

    تحتاج Git. السطر الأول ينسخ المشروع لجهازك والثاني يدخل مجلده.

    بالطرفية

  2. جهّز المشروع

    هذا الأمر يركّب كل شي يحتاجه. إذا ما عندك make (غالباً بويندوز) فيه طريقة يدوية بصفحة المشروع.

    بالطرفية

  3. شغّل Claude Code داخل المجلد

    لازم تكون داخل مجلد OpenMontage حتى يشوف ملفاته.

    بالطرفية

  4. اكتب طلبك

    اوصف الفيديو بكلامك.

    داخل Claude Code

    النتيجة: كلود يختار مسار إنتاج من الـ12 وينفّذه خطوة بخطوة.

مصطلحات بكلام بسيط

الطرفية (Terminal)
نافذة تكتب بيها أوامر بدل ما تضغط أزرار. بويندوز ابحث عن PowerShell من قائمة ابدأ. بماك افتح تطبيق Terminal. تلصق الأمر وتضغط Enter.
Claude Code
أداة من Anthropic تشتغل بالطرفية: تكتب لها طلبك بالكلام وهي تنفّذه على ملفاتك.
Node.js
برنامج يشغّل أدوات مكتوبة بـJavaScript. HyperFrames وRemotion وOpenMontage تحتاجه.
FFmpeg
برنامج مجاني يقرأ الفيديو والصوت ويركّبهم ويصدّرهم بملف MP4.
Git وGitHub
GitHub موقع تنحفظ عليه مشاريع البرمجة، وGit أداة تنزّل منه المشروع لجهازك (git clone).
مهارة (Skill) وإضافة (Plugin)
تعليمات جاهزة تعلّم كلود يشتغل بأداة معيّنة. تنصيبها بسطر واحد وتبين لك كأوامر تبدأ بـ/.
MP4
صيغة ملف الفيديو العادية، تنفتح بكل جهاز وتنرفع على إنستغرام.

ملاحظات صادقة

عدد النجوم حسب GitHub بتاريخ 2026-11-04. الأوامر من التوثيق الرسمي لكل مشروع.

  • الاشتراك: Claude Code يحتاج حساب Claude (اشتراك أو Console)، وهذا مو مجاني.
  • الوقت: الرندر يشتغل على جهازك، فياخذ وقت حسب طول الفيديو وقوة الجهاز.
  • النتيجة: جودة الفيديو تعتمد على وضوح طلبك. جرّب طلب صغير أول.
  • Remotion: له شروط ترخيص خاصة. راجع remotion.dev/docs/license ↗ قبل أي استعمال تجاري.
  • OpenMontage: ترخيصه AGPLv3، وبعض أدواته تحتاج مفاتيح خدمات خارجية (مدفوعة غالباً) وبعضها يشتغل محلياً بدونها.
  • إذا علقت: دليل حل مشاكل التنصيب الرسمي ↗ أو اسأل كلود نفسه عن الخطأ اللي طلع.
