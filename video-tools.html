٣ أدوات تخلي كلود يمنتج لك فيديو

وصلت من الريل؟ هذي الأوامر والروابط كلها. HyperFrames وRemotion وOpenMontage: ثلاث مشاريع على GitHub تشتغل مع كلود كود. تحت كل أداة: شنو تسوي، الأمر الجاهز للنسخ، وشنو تحتاج على جهازك.

شلون تبدأ؟

ثلاث خطوات.

01

جهّز المتطلبات

Node.js وFFmpeg على جهازك (التفاصيل تحت كل أداة).

02

انسخ أمر الأداة

كل أمر تحته زر COPY. الصقه بالطرفية أو بكلود كود حسب الأداة.

03

اكتب طلبك بكلامك

مثل «سوّي لي إعلان ريل لمطعم برجر» وكلود يسوي الباقي.

الأدوات الثلاث

عدد النجوم حسب GitHub بتاريخ 2026-11-04. الأوامر من التوثيق الرسمي لكل مشروع.

HYPERFRAMES★ 78K

HyperFrames

تكتبله الفكرة بكلامك، وكلود يكتب الفيديو بـHTML وينفّذه فيديو MP4 جاهز.

الاستعمال: ثبّت الإضافة بكلود كود، وبعدها اكتب طلبك بعد الأمر /hyperframes:hyperframes.

تحتاج: Node.js 22 أو أحدث وFFmpeg. السطر الأخير طريقة بديلة (مهارات لأي وكيل) إذا ما تستعمل إضافات كلود كود.

github.com/heygen-com/hyperframes ↗

REMOTION★ 71K

Remotion

تبني الفيديو بكود React، ومناسبة للأرقام والجداول والرسوم. تنصّب مهاراتها بسطر واحد وكلود يتعلّم أفضل طريقة للعمل بيها.

الاستعمال: بعد التنصيب تظهر أوامر مثل /remotion-create و/remotion-best-practices.

تحتاج: مشروع Remotion (Node.js). لـRemotion شروط ترخيص خاصة: راجع remotion.dev/docs/license قبل أي استعمال تجاري.

github.com/remotion-dev/remotion ↗

OPENMONTAGE★ 76K

OpenMontage

استوديو إنتاج فيديو كامل يشغّله كلود: 12 مسار إنتاج جاهز. تنزّله وتكتب طلبك بكلامك.

الاستعمال: نزّل المشروع، شغّل make setup، وافتح كلود كود داخل مجلده واكتب طلبك.

تحتاج: Python 3.10+ وFFmpeg وNode.js 18+. بعض الأدوات داخله محلية وبعضها يحتاج مفاتيح خدمات خارجية. الترخيص AGPLv3.

github.com/calesthio/OpenMontage ↗
